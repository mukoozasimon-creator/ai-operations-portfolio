# AI Ops Control Room

An interactive demonstration and learning tool explaining identity, access, ownership and operating controls. SSO, SCIM and RBAC are illustrated concepts, not connected enterprise services. This is not the private AI_Ops workspace described in my application.

[Live demonstration](https://ai-ops-control-room.netlify.app/)

## Read and run

Start with `index.html`; browser JavaScript and styles are inline or in adjacent files. No API key is required. From the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory projects/ai-ops-control-room
```

Open http://localhost:4173/. Stop the server before previewing a different project. This basic preview does not apply Netlify `_headers` or `_redirects`.
