# AI Adoption Engine

An interactive reference model for trying, checking, sharing and improving AI use. Examples are invented; no live AI, accounts or business systems are connected.

[Live demonstration](https://ai-adoption-engine.netlify.app/)

## Read and run

Start with `index.html`; browser JavaScript and styles are inline or in adjacent files. No API key is required. From the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory projects/ai-adoption-engine
```

Open http://localhost:4173/. Stop the server before previewing a different project. This basic preview does not apply Netlify `_headers` or `_redirects`.
