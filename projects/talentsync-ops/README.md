# TalentSync Ops

A static concept for people, talent and customer success workflows, including guided puzzles and a sample workspace. Records are fictional and matching results are fixed examples. No live AI, database, messaging or calendar integration is connected.

[Live demonstration](https://talentsync-ops.netlify.app/)

## Read and run

Start with `index.html`; browser JavaScript and styles are inline or in adjacent files. No API key is required. From the repository root:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory projects/talentsync-ops
```

Open http://localhost:4173/. Stop the server before previewing a different project. This basic preview does not apply Netlify `_headers` or `_redirects`.
